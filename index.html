Git LFS for Windows
git-lfs-windows-amd64.exe · Official installer
Download
1
Run the installer
Double-click the downloaded git-lfs-windows-amd64.exe and follow the setup wizard. Git LFS integrates directly into your Git installation.
2
Open Git Bash or Command Prompt
You need a terminal to run Git commands. Here's how to find one:
Git Bash
After installing Git, right-click any folder on your Desktop or in File Explorer and choose "Git Bash Here" — or search Git Bash in the Start menu.
CMD
Press Win + R, type cmd and press Enter — or search Command Prompt in the Start menu.
PowerShell
Search PowerShell in the Start menu, or right-click the Start button and choose "Windows PowerShell" — works great for Git too.
Then hit Ctrl + V together, then Enter
git lfs install
3
Clone the repo with LFS files
All LFS-tracked files (overlay.js, background.js, auth.js, popout.js, recovery.js) will be downloaded automatically.
git clone https://github.com/ridgejohnston/Apex-Revenue-Edge.git
4
Or pull LFS files into existing clone
If you already cloned the repo without LFS, fetch the real files:
git lfs pull

Install via Homebrew (easiest)

Open Terminal
You need a terminal to run these commands. Here's how to open one:
Spotlight
Press ⌘ Command + Space to open Spotlight, type Terminal, then press Enter. This is the fastest way.
Finder
Open Finder → Applications → Utilities → double-click Terminal.
iTerm2
If you use iTerm2, open it the same way — all commands below work identically.

Git LFS for Linux
Debian/Ubuntu · RHEL/Fedora · Arch · Manual
Download .tar.gz
1
Install via package manager
Debian / Ubuntu:
sudo apt-get install git-lfs
RHEL / Fedora / CentOS:
sudo yum install git-lfs
Arch Linux:
sudo pacman -S git-lfs
2
Open a Terminal
Most Linux desktops have a keyboard shortcut to open a terminal:
Shortcut
Press Ctrl + Alt + T — works on Ubuntu, Debian, Linux Mint, and most GNOME / KDE desktops.
Right-click
Right-click an empty area on your Desktop and choose "Open Terminal" or "Open in Terminal".
App menu
Search Terminal or Konsole in your application launcher (Super key on GNOME / KDE).
Then hit Ctrl + Shift + V together, then Enter
git lfs install
3
Clone the repo with LFS files
git clone https://github.com/ridgejohnston/Apex-Revenue-Edge.git
